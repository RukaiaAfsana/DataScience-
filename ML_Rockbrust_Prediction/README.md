# Rockburst Prediction Using Data-Driven Machine Learning

This repository contains the implementation of a machine learning approach for predicting rockburst risks using in-situ seismic monitoring data. The study aims to address the inherent challenges of geological variability, dynamic stress conditions, and limited high-quality sensor data by leveraging modern data-driven techniques.

## 🌍 Project Motivation

Predicting rockbursts in underground environments is notoriously difficult due to:

- Geological variability among rock masses.
- Dynamic stress redistribution during excavation.
- Unclear correlation between stress changes and rock failure.
- Limited and inconsistent sensor data from in-situ monitoring systems.

These issues make traditional predictive methods less effective. This project proposes a **data-driven machine learning solution** to overcome these limitations and provide a robust predictive model for rockburst risk assessment.

## 🎯 Objectives

The main goal is to develop an accurate ML-based framework to predict rockburst risks through seismic resilience analysis. Specific objectives include:

1. Investigate state-of-the-art methods for Rockburst Fragility Surfaces.
2. Perform statistical analysis and preprocessing of in-situ monitoring datasets.
3. Design and optimize a model to generate 3D fragility curves for risk prediction.
4. Generate interpretable 3D fragility surfaces.
5. Evaluate and validate the predictive performance of the developed system.



## 📊 Methods

- Supervised machine learning algorithms (e.g., XGBoost, Random Forest)
- Feature scaling and statistical preprocessing
- SHAP (SHapley Additive exPlanations) for model interpretability
- Fragility surface generation for 3D risk visualization
